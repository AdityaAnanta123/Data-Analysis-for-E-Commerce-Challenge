# 🛒 Data Analysis for E-Commerce Challenge

Proyek ini merupakan studi kasus analisis data e-commerce menggunakan **MySQL**. Tujuannya adalah untuk mengevaluasi performa penjualan dan memberikan wawasan bisnis berdasarkan data transaksi yang tersedia. Proyek ini merupakan bagian dari pelatihan yang diselenggarakan oleh DQLab, dengan fokus pada penguatan kemampuan dalam pengolahan dan analisis data menggunakan SQL.

## 📁 Struktur Proyek

```
├── DataAnalysisForEcommerceChallenge.sql
├── orders.csv
├── order_details.csv
├── products.csv
├── users.csv
└── README.md
```

## 🧰 Teknologi yang Digunakan

- **MySQL**: Digunakan untuk membuat skema database, mengimpor data, dan menjalankan query analisis.
- **CSV Files**: Dataset terdiri dari empat file CSV yang mencakup informasi pengguna, produk, pesanan, dan detail pesanan.

## 🎯 Tujuan Analisis

- Membuat skema database relasional untuk data e-commerce.
- Mengimpor data dari file CSV ke dalam tabel MySQL.
- Menjalankan query untuk menganalisis performa penjualan, termasuk total penjualan, produk terlaris, dan pelanggan terbaik.
- Mengidentifikasi tren dan pola dalam data untuk mendukung pengambilan keputusan bisnis.

## 📈 Hasil dan Insight

Analisis ini menghasilkan berbagai wawasan bisnis, seperti:

- Identifikasi produk dengan penjualan tertinggi.
- Pelanggan dengan total pembelian terbesar.
- Tren penjualan berdasarkan waktu.
- Efektivitas diskon terhadap volume penjualan.

Wawasan ini dapat digunakan untuk strategi pemasaran, pengelolaan inventaris, dan peningkatan layanan pelanggan.

## 🚀 Cara Menjalankan Proyek

1. Pastikan MySQL telah terinstal di sistem Anda.
2. Buat database baru di MySQL.
3. Jalankan script `DataAnalysisForEcommerceChallenge.sql` untuk membuat tabel dan mengimpor data dari file CSV.
4. Gunakan query SQL tambahan untuk melakukan analisis sesuai kebutuhan.

## 📌 Catatan

- Pastikan file CSV (`orders.csv`, `order_details.csv`, `products.csv`, `users.csv`) berada di direktori yang sama dengan script SQL atau sesuaikan path file dalam script sesuai dengan lokasi file Anda.
- Data yang digunakan bersifat simulasi dan digunakan untuk tujuan pembelajaran.
